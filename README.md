# TaskFlow - Nintendo 2001 Edition 🎮

A retro, fully interactive task manager built to look and feel like the Nintendo.com website from 2001. This project demonstrates vanilla JavaScript logic, DOM manipulation, and localStorage persistence, wrapped in a unique console-chrome aesthetic.

## 🚀 Live Demo
> *Click the link below to try it out!*
> **[View Live Demo](https://nisaruddin-dev.github.io/taskflow-nintendo/)** *(Note: You might need to enable GitHub Pages in the Settings tab for this to work).*

## 📋 Features
- **Add, Edit, and Delete** tasks with an intuitive form.
- **Mark tasks as complete** with a visual strike-through.
- **Drag & Drop** to reorder your list.
- **Filter** by All, Pending, Completed, or High Priority.
- **Search** and **Sort** (by Newest, Oldest, Priority, Due Date, or Alphabetical).
- **Local Storage** persistence (tasks stay saved even after refreshing).
- **Export & Import** your data as a JSON backup file.

## 🎨 Design Aesthetic
This app utilizes a `DESIGN.md` design spec based on the **Nintendo.com (2001) console chrome aesthetic**. It features:
- Periwinkle metallic panels (`canvas`)
- Carbon command slabs (`carbon`)
- Warm Signal Orange accents (`signal`)
- Beveled, chamfered (sharp-edged) paneling

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- GitHub Copilot (Used to assist with styling and implementing the `DESIGN.md` spec)

## 📂 How to Run Locally
